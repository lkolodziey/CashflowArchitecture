# ADR-005: hybrid-consolidation

## Status
Aceito

## Contexto
Decisão tomada para o desafio de arquitetura de fluxo de caixa diário, priorizando clareza, desacoplamento e execução local reprodutível.

## Decisão
Adotar a abordagem indicada no título deste ADR.

## Consequências
- Mantém o escopo controlado.
- Documenta trade-offs conscientemente.
- Permite evolução futura para cenários corporativos mais robustos quando necessário.
